# 🚀 Getting Started with Your Construction CRM

## What You Have

A complete, free Customer Relationship Management system with:
- Customer management
- Project tracking
- Quotes & estimates
- Task management
- Invoice tracking
- Real-time dashboard
- Financial reports

## Installation (5 Minutes)

### Step 1: Install Node.js
Download from https://nodejs.org (choose LTS version)

### Step 2: Navigate to the folder
```bash
cd construction-crm
```

### Step 3: Install dependencies
```bash
npm install
```

### Step 4: Start the CRM
```bash
npm start
```

### Step 5: Open in browser
```
http://localhost:3000
```

That's it! ✅

## Your First Steps

1. **Add a customer** - Click "👥 Customers" and add your first client
2. **Create a project** - Link a project to that customer
3. **Make a quote** - Generate a professional quote
4. **Track tasks** - Break the project into tasks
5. **Create invoice** - Bill when work is complete
6. **View dashboard** - See all your stats
